## Package promotions (`R/tv_ball_correlation_IF_adaptive.R`)

Two new optional arguments, both default `FALSE` (backward compatible):

### `jackknife = FALSE`
Grouped delete-block jackknife (G=20) bias correction. Ported from
`simulations/generality-validation/R/estimators.R` (Phase 0 validated). Vectorized
over Q draws — no MCMC refit. Returns `rho_jk`, `jk_bias`, `ci_lower_jk`,
`ci_upper_jk`. IW method only (warns otherwise).

At n=5,000 on dgp1: plug-in 0.589 → jk 0.640 (true: 0.691).

### `debiased = FALSE`
One-step tr(Σ V)/n bias correction (Corollary A10 of the proof). Computes sample
geometry kernel Σ (K×K Cov_μ(q_k, q_k') from Q draws) and per-cell CATE-score
cross-covariance V, then applies the correction to Cov_μ(Δ_S, Δ_Y) and propagates
to rho via the delta-method gradient. Returns `rho_os`, `os_bias_correction`,
`ci_lower_os`, `ci_upper_os`. IW method only.

Also added `jackknife_groups` argument (default 20) for the jackknife group count.

**Tests:** 22 new tests in `tests/testthat/test-bias-corrections.R`. Full suite:
1510 tests, 0 failures. Docs regenerated (`man/tv_ball_correlation_IF_adaptive.Rd`).

### Generality validation — **INVALID, needs rerun**
Results file: `simulations/generality-validation/results/20260717-082417_5d07c37.rds`

**All 24,000 rows are collapsed:** every rep within each of the 48 configs returned
the identical estimate and SE (0 variance across reps, confirmed).

**Root cause diagnosed and fixed:**
`draw_random_dgp(rng_seed=dgp_seed)` calls `set.seed(dgp_seed)` internally
(line 31 of `R/random_dgp.R`), clobbering the per-rep data seed set by
`run_one()`. Since all 500 reps in a config share the same `dgp_seed`, every rep
ran on the same RNG state and produced identical data.

**Fix applied:** `simulations/generality-validation/R/dgp.R` now saves
`.Random.seed` before calling `draw_random_dgp()` and restores it afterward, so
the per-rep seed from `run_one()` survives. Fix verified locally — data now
differs across reps, spec still reconstructs identically from `dgp_seed`.

**What was actually received:** 48 unique point estimates (one valid draw per DGP
seed) — these are the correct estimate values for each DGP at one replication.
The truth values are valid. But coverage, bias, SE calibration: all meaningless
(single rep each).
