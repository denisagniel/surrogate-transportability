## 10:30 — M_max decision, n-grid extension launched and completed

**Goal.** Decide whether to raise `M_max` (per the prior turn's finding that
728/1120 units hit it without "converging"), then launch the promised
finite-sample n-grid extension for confounded-aipw.

**M_max decision.** Consulted Oracle with the full convergence-rate breakdown
(100% at rho~1, 2.5-29% on the confounded DGPs) and the observed n=10000 cost
overrun (81s median vs. the sizing model's 32s). Oracle derived a closed form
(`sd(rho_hat) ~= (1-rho^2)/sqrt(M)` for nested draws) reproducing the entire
table without touching M_max, and computed `se_mc` directly on the completed
run: <=18.5% (median 5.3%) of the IF SE for every unit, converged or not — the
`converged` flag never carried real information. Verdict: do not raise M_max;
fix the stopping rule itself (MC-precision test) and a real O(n*M*K) perf bug
(`which(X_unique==...)` inside `n x M` loops, 7 sites); keep M_max=1500 flat
across the whole n-grid including n=40000 (required M for adequate precision
there is ~646, well under 1500).

**Implementation.** Delegated the package fix to a `deep`-category subagent
with skills `developing-packages-r`/`testing-r-packages`/`optimizing-r`
(session `ses_f175138f9ffeVz4N8wmGLgZrv6`): replaced the difference-window
stopping rule with `se_mc = (1-rho^2)/sqrt(M) < mc_tolerance` (new arg, default
0.02), hoisted the O(K) linear search to one `match()` call, added `se_mc` as
an unconditional return field, wrote a testthat case and an empirical
validation script (`validation/validate_mc_error_formula.R`: 50 runs at fixed
M=1500 varying only the sampler seed). Full suite: 1628 pass, 0 fail. Empirical
ratio (true sd / plug-in `se_mc`) came back 1.33-1.56 depending on reference
point — borderline against Oracle's 1.5 flag threshold. Decided to keep
`mc_tolerance=0.02` rather than tighten to 0.01: even inflated, true MC error
stays under a third of the statistical SE, and tightening would ~4x the
required M for exactly the DGPs about to run across a bigger grid. Bumped
